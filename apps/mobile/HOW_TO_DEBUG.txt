--------------------------------------------------------------------------------
  COMMON SCENARIOS
--------------------------------------------------------------------------------

Scenario A: Stops at 🔥 (Firebase Config shows "false" or "undefined")
  Problem: .env file not being read
  Fix: pnpm start --clear
  Details: See GET_APP_RUNNING.md

Scenario B: See 🔥 but not 📱
  Problem: JavaScript error preventing React from loading
  Fix: Look for RED ERROR TEXT in console
  Details: See DEBUGGING_GUIDE.md

Scenario C: See 📱 but not 🔐
  Problem: FirebaseProvider not mounting
  Fix: Check for errors in Metro console
  Details: See ACTION_PLAN.md Step 8

Scenario D: See 🔐 but not ✅
  Problem: App stuck in loading state
  Fix: Check for JavaScript errors
  Details: See DEBUGGING_GUIDE.md Issue 2

Scenario E: See ✅ but not 🔍
  Problem: Index screen not rendering
  Fix: Check expo-router installation
  Details: See ACTION_PLAN.md Step 9

Scenario F: See 🔍 and navigation log, but screen is blank
  Problem: Target screen file missing or broken
  Fix: Check that app/auth/login.tsx exists
  Details: See DEBUGGING_GUIDE.md Issue 5
