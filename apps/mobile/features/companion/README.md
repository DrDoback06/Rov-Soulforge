# 🐾 Companion System

## Overview
Pet/companion system for players.

## Structure
- `display/` - Companion UI
- `management/` - Companion stats and abilities
- `hooks/` - React hooks (useCompanion)

## Key Features
- Companion acquisition
- Companion leveling
- Companion abilities in battle
- Companion customization

## AI Editing Guide
- Change companion stats: `management/CompanionManager.ts`
- Modify companion AI: `management/CompanionAI.ts`

## Firebase: `/characters/{id}/companions/`
